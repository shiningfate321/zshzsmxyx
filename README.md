来源：https://jsdh.de5.net/games/jujutsu-wheel-normal-v1  
提取日期：2026-10-21  
原页面作者署名：芙丽莲大王（已保留在 HTML 中）。

这是从已正常加载的网页提取的前端运行代码，不是作者的原始代码仓库。核心脚本保留了原游戏的玩法、剧情与数值，并在此基础上加入了阵营好感、生死处置、死战红条与撤退/生还轮盘、连续速度、双形态速度等自定义规则。原代码已有中文注释，可以直接编辑。

## 如何运行

单人模式可尝试直接用 Chrome 或 Edge 打开 `index.html`。推荐使用本地服务：

1. 此电脑已有 Node.js，双击 `启动游戏.cmd`。
2. 浏览器打开 `http://127.0.0.1:8765`。
3. 修改文件后刷新页面即可。关闭命令窗口或按 Ctrl+C 停止服务。

也可以在此目录运行 `node server.cjs`，再自行打开上述网址。服务器只监听本机地址，仅提供静态文件，不负责游戏运算。默认端口被占用时，先停止已有服务，或设置环境变量 PORT 更换端口并手动打开对应网址。

## 自定义规则 v3

### 1. 阵营与好感

阵营分为高专阵营、诅咒阵营、中立阵营，好感度范围 −100 至 +100。

| 初始选择 | 高专好感 | 诅咒好感 |
| --- | --- | --- |
| 高专阵营 | +50 | −50 |
| 诅咒阵营 | −50 | +50 |
| 中立阵营 | 0 | 0 |

**中立阵营**

- 杀死一方具名角色：另一方好感 +10，被杀方好感 −30。
- 打败但放过：败方所处阵营好感 +10，并计入该阵营的特殊生还记录。

**已有明确阵营**

- 杀死敌对阵营：己方好感 +10，敌方好感 −10。
- 杀死己方阵营：己方好感 −120，敌方好感 +20；随后**立即被逐出己方阵营，转为中立**。此后该阵营好感增加减半、减少加倍（永久记录）。
- 因为 ±50 只是初始值，−120 是对**当前好感**做减法：当前 +100 → 最终 −20；当前 +50 → −70；当前 ≤+20 → −100。
- 诅咒阵营杀死不是特级的咒灵：不降低己方好感，也不触发背叛惩罚。

> 好感与生死处置只对具名剧情角色结算；野生咒灵、杂兵、式神不弹窗、不改变阵营好感。

### 2. 战胜后的杀死 / 放过

- 战斗胜利时读取结算前生命值；生命高于 30% 才逐个弹出「杀死 / 放过」选择。
- 生命不高于 30% 时不提供选项，默认击杀，并照常结算好感。
- 杀死后，同一角色的其他形态一并记为「已阵亡」，不再出现在后续剧情战斗中；放过则保留其后续出场可能。
- 剧情文本提到已阵亡角色时，会在名字后标注「（已阵亡）」，并保留原剧情文本。

### 3. 死战撤退与生还轮盘

死战不再弹出战前提醒，只在战斗上方保留红色提示。

**撤退轮盘**：死战选择撤退时进入。

- 成功：进入下一轮，无奖励。
- 失败：继续当前战斗，并消耗本次行动。
- 轮盘概率使用第 6 节的撤退公式；非死战仍直接判定。

**生还轮盘**：死战败北时进入，分两种。

- **特殊生还**：曾放过该阵营角色，且从未击杀该阵营任何人。高专阵营 70%，诅咒阵营 30%。
- **普通生还**：该阵营好感大于 70。概率 = 40% + (好感 − 70) × 1%，上限 70%。
- 每个阵营取较高的一项；混合敌队取最不愿放过的阵营；真人（含混编敌人中的真人）一票否决。
- 进入哪种轮盘由较高概率决定；概率为 0 时不进入轮盘，直接死亡。
- 生还成功没有战胜奖励。

**加入 / 倒戈**

- 某阵营好感 ≥50 时，可在阵营详情中选择加入。
- 中立加入一方：另一方好感 −30。
- 已有阵营者倒戈：原阵营好感 −100（固定扣值，不受背叛倍率影响）。

### 4. 连续速度

速度不再只看档位，而是「档位 + 档内进度」：

```
hpTier = hpTierIndexOf(maxHp)
hpPos = (maxHp − 该档下限) / (该档上限 − 该档下限)
hpScore = hpTier + hpPos

effTier = tierIndexOf(eff[1], DMG_TIERS)
effPos = (eff[1] − 该档下限) / (该档上限 − 该档下限)
effScore = effTier + effPos

B = 9.375 + 1.25 × hpScore
W = 0.88 + 0.02 × effScore
速度 = B × W × 术式最高倍率
```

- 咒力效率取 `eff[1]`（伤害区间上限）。
- 档位内每一点 HP/咒效成长都会让速度连续变化，不再出现「没跨档就完全没提升」。
- 具名 NPC 的 HP 取档位中点或固定值；`eff[1]` 取该档上限。
- 多个速度术式**取最高**，不叠乘。

速度术式倍率：

| 术式/状态 | 倍率 | 备注 |
| --- | ---: | --- |
| 无下限·苍加速 | ×1.1 | 五条悟可用来高速移动 |
| 投射咒法 | ×1.45 | 有效速度保底 20（减速前）；近战×0.25、咒术×0.5 |
| 神速 / 幻兽琥珀常态 | ×1.3 | 五宿级别 |
| 幻兽琥珀·开启 | ×1.8 | 超越五宿 |
| 质量的杀意与光常态 | ×1.25 | 五宿级别 |
| 亚光速形态 | ×2.5 | 极快 |
| 付丧操术 | ×1.2 | — |

### 5. 幻兽琥珀与亚光速

**NPC 触发**：鹿紫云一、达布拉在 HP<40% 时自动进入对应形态。

**玩家触发**：拥有对应术式时，战斗界面多出「幻兽琥珀」或「亚光速形态」按钮，随时可点，不自动触发。

**幻兽琥珀**

- 常态速度×1.3，开启后×1.8。
- 开启时弹出确认框。
- 开启后本场战斗**无法撤退**，撤退按钮变灰。
- 战斗结束（无论胜、负）后玩家必定死亡；不能靠复活、死而替生、奇迹规避。
- 若这是多连战，当前战斗结束后终止；若赢了最终战，也改为「幻兽琥珀反噬」死亡结局。
- NPC 开启后也会在战斗结束后被反噬；引擎会记录其死亡。

**亚光速形态**

- 速度×2.5，持续整场战斗。
- 该单位所有咒力消耗×3（术式、领域、极之番、反转、无下限维持、单独禁区、咒言、奇迹等）。
- 每次实际行动损失 5% 最大生命。
- 连续三次战斗内只能使用一次：用后接下来两场不可用，第三场结束后解锁。
- 若玩家掌握反转术式，则没有这个冷却限制；但 5% 生命损失仍然保留。

### 6. 撤退与轮盘

```
r = 己方有效速度 / 最快敌人有效速度

r ≥ 1.3        → 100%
r < 0.7        → 0%
0.7 ≤ r < 1.3  → clamp(0.5 × 血量百分比比, 5%, 75%)
血量百分比比 = (己方HP/己方MaxHP) / (最快敌人HP/最快敌人MaxHP)
```

- 死战撤退进入**撤退轮盘**：成功进入下一轮且无奖励；失败继续当前战斗并消耗本次行动。
- 非死战仍直接判定，不进入轮盘。
- 同速同血为 50%；多敌人只看**最快敌人**的血量百分比。
- 投射咒法的保底 20 在减速前生效；减速仍可把有效速度压到 20 以下。
- 幻兽琥珀开启后无法撤退。

### 7. 总战力

总战力系统保持原样，不改：

```
cp    = 咒力总量档
ctl   = 咒力操控档
melee = 体术伤害档
eff   = 咒力效率档
hp    = 体质档

加权 = eff×0.24 + hp×0.22 + cp×0.18 + ctl×0.18 + melee×0.18
硬顶 = min(eff, hp) + 2
综合评级 = clamp(min(round(加权), 硬顶), 0, 15)
```

NPC 的 `li` 由剧情/NPC_CHARS 手动指定，不等于 `evalLevel` 的结果；例如伏黑甚尔按五维公式会被硬顶到很低，但剧情等级仍是 9。

## 前端与联网边界

- 单人模式的随机抽取、角色成长、剧情和战斗在浏览器中执行；未发现向服务器提交这些计算的代码。
- 音效使用 Web Audio 程序合成，语音使用浏览器的语音合成功能。语音可用性及是否离线取决于系统、浏览器和所选语音。
- 同设备多标签页对战使用 BroadcastChannel，建议让所有标签页打开同一个本地服务地址。
- 局域网直连使用 WebRTC 和手动交换连接码，原配置包含公共 STUN 地址。
- 跨网对战使用 PeerJS 云信令服务和公共 STUN 服务，仍然需要网络。下载 PeerJS 库不等于把信令服务器搬到了本地；复杂 NAT 环境也不保证能连通。
- 原版仅将音效、语音开关与转盘速度写入 localStorage。没有完整的单人进度保存；刷新可能丢失当前进度，阵营好感、死亡名单与亚光速冷却也随当前页面会话存在。
